# Simple UI Components Example

这个示例演示了 Deft UI 框架中各种基础 UI 组件的使用。

## 功能特性

- 标签（Label）
- 按钮（Button）
- 文本输入（TextInput）
- 容器布局（Container）
- 滚动视图（ScrollView）
- 简单的事件处理

## 运行方式

```bash
cd examples/simple-ui-components
cargo run
```

## 代码说明

### Rust 入口 (src/main.rs)

设置应用程序并加载 JavaScript 模块。

### JavaScript UI (src/index.js)

创建和配置所有 UI 组件，包括：
- 欢迎标题
- 交互式按钮
- 文本输入框和显示
- 列表视图

## 学习要点

1. 如何创建基础 UI 元素
2. 如何设置样式和布局
3. 如何处理用户事件（点击、输入等）
4. 如何动态更新 UI
